# Form Field: Email Input

### Type: `email`

Text input with built-in email format validation.

```javascript
{
  id: 'email',
  type: 'email',
  label: 'Email',
  placeholder: 'your@email.com',
  defaultValue: '',
  required: true,
  disabled: false
}
```
| Property | Type | Description |
|---|---|---|
| `placeholder` | string | Field placeholder |
